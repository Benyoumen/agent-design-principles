# Write contract table

One row per control on the screen. Fill it from the rendered output, then confirm each field against the live API.

| Control | Where it appears | Class | Target in system of record | Field exists? | Verdict | Comment |
|---|---|---|---|---|---|---|
| | | action on record / response about recommendation | object and field names | exists and filled / exists and empty / pair only / no | stays / stays after creating a field / leaves / other product | |

## Verdicts

- **Stays.** The field exists today.
- **Stays after creating a field.** Worth it and the system owner approves.
- **Leaves.** No destination and no reason to exist.
- **Other product.** Belongs elsewhere and does not write back.
